# 学习路线

## 第 1 阶段：先建立物理直觉

阅读 Page & Tuple Layout，理解 Page、Slot、RID 和 TableHeap。然后阅读 P1，跟踪一个页从磁盘进入 Frame，再被 Guard 释放的完整生命周期。

## 第 2 阶段：在页之上组织数据

按 P2 阅读 B+Tree，再对照 Extendible Hash。重点是理解分裂、合并、墓碑与并发锁如何共同维护不变量。

## 第 3 阶段：让系统执行查询

阅读 P3，画出一棵执行器树，区分流式算子与阻塞算子，再观察索引如何改变访问路径。

## 第 4 阶段：加入时间与故障

最后阅读 P4 和 WAL 专题：一个解决并发快照，一个解决机器崩溃。

## 每章都可以问自己的问题

1. **状态放在哪里？** 是页头、内存表、事务对象，还是日志记录？
2. **谁负责释放？** 看到 `pin`、锁或临时版本时，继续追踪所有权和释放路径。
3. **失败时怎么办？** 插入中途页分裂、事务中止、进程崩溃时，不变量如何恢复？
4. **如何证明有效？** 找到覆盖边界条件的测试，并尝试构造一个反例。

## 一条实践线

选一个简单查询（`SELECT * FROM table WHERE id = 7`），在源码中依次追踪 SQL 解析、计划生成、IndexScan、RID 定位、Buffer Pool 取页和 Tuple 返回；再改成范围条件，观察 B+Tree 叶子链和迭代器的差异。
